# Паспорт Модель4 r05

Источник: полная нативная сборка Модель4, подготовленная в предыдущих ревизиях без удаления панелей. Целевая среда: БАЗИС 2022.12.21.36090, API 2341. Материалы, кромки, фурнитура и ограничения перенесены из исходной сборки; их замена не предусмотрена.

Входы в мм: ширина 450–800, высота корпуса без опор 712–862, глубина с задником без фасада 513–600. Исходная рамка 600×762×523. Добавление нового полного эластичного блока справа в прямой ряд по X, вплотную боковинами, с общей передней плоскостью. Существующие объекты не меняются. Сборка содержит 211 объектов, включая 15 панелей; сохранены корпус, фасады, ящики и GOLA.

Генератор работает в БАЗИС самостоятельно, без ИИ. Отдельного фонового запуска БАЗИС без графической сессии эта ревизия не реализует. Производственный допуск отсутствует.
