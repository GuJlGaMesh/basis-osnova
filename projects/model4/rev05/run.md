# Запуск Модель4 r05

Скопируйте содержимое `src` в папку `Model4-r05` каталога скриптов БАЗИС. `model4.js` и `lib/native-module.fr3d` должны оставаться рядом в указанной структуре. ИИ и подключение к нему для работы не нужны.

Меню «Скрипты» → «Model4-r05» → «model4». Введите ширину, высоту и глубину через пробел, например `600 762 523`. Диапазоны: Ш 450–800, В корпуса без опор 712–862, Г с задником без фасада 513–600 мм.

Новый модуль добавляется справа вплотную к боковине, фасады выравниваются по лицу, низ панелей — по Y=0. Поддержан прямой ряд по X с лицом вдоль Z. Прежние модули остаются; повторный запуск добавляет ещё один. Отмена и неверный ввод ничего не строят. Сохраните результат средствами БАЗИС под новым именем.

Для другого размера создавайте новый экземпляр из шаблона. Произвольные циклы ручного растяжения не входят в подтверждённую область этой ревизии. Не запускайте архивные r02–r04.

В случае ошибки сохраните текст и `model4-last-run.json` рядом со скриптом, укажите введённые размеры и действие. Пример `model4-r05-scene.b3d` содержит два модуля 600×762×523 и 800×862×600. Проверки разработки не нужно выполнять при каждом запуске.
