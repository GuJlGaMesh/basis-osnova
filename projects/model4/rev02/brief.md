# Паспорт Модель4

ID: model4. Ревизия: 02. Дата: 2026-09-05. Задача: воспроизведение исходной конструкции скриптом с уменьшением и увеличением размеров без масштабирования толщин и фурнитуры. Запуск агентом прямо разрешён пользователем.

Среда подтверждена запуском: БАЗИС-Мебельщик 2022.12.21, system.apiVersion=2341. Исходник: Модель4.b3d; хеш в evidence/original-integrity.json.

| Параметр | Исходное значение | Поддержанный диапазон | Основание |
|---|---:|---:|---|
| W, наружная ширина | 600 мм | 450…800 мм | Измерение исходника; границы реализации проверены геометрически |
| H, высота корпуса без опор | 762 мм | 712…862 мм | Нативная размерная рамка |
| D, глубина с задником без фасада | 523 мм | 513…600 мм | Нативная рамка, фиксированная фурнитура L=500; API ограничивает рост до 600 |
| Высота опор | 100 мм | Не изменяется | Исходник |
| Плита корпуса | 16 мм | Не изменяется | Egger U705 ST9, свойства исходника |
| Фасады | 2 × 597×346×18 мм | Ширина W−3, высота H/2−35 | Исходные контуры и размерные связи |
| Ящики | 3 сборки TANDEMBOX antaro L=500 | Меняется ширина, монтажная длина сохраняется | Нативные узлы |
| Состав | 212 объектов, 15 панелей | Не изменяется | Рекурсивная выгрузка |

Габарит с опорами по высоте H+100, с фасадами по глубине D+18. Начало отсчёта корпуса по Y=0, низ опор Y=−100. При изменении D задняя плоскость остаётся Z=−523, фасады перемещаются к Z=D−523.

Диапазоны являются границами проверенной реализации, не допустимыми нагрузками производителя. Техника, монтажная ниша, нагрузки, производственные допуски и технологический выпуск неизвестны; в этом комплекте они не назначаются. Поручение воспроизвести модель подтверждает её сохранённые материалы и узлы для геометрической копии.

Точный новый размер задаётся повторным запуском скрипта. Результат содержит нативный эластичный блок, однако произвольная цепочка ручных растяжений имеет ограничение служебной рамки внутреннего ящика; см. qa.md. Исходные файлы и другие открытые документы сохраняются.
