# Запуск Модель4 r02

1. Сохраните нужное содержимое текущего документа. При запуске скрипт очистит текущую модель и построит изделие заново; нужное содержимое сохраните заранее. Пустая модель не обязательна.
2. Перенесите папку src целиком: model4.js и соседняя lib/hardware-template.b3d должны оставаться вместе. Среда: БАЗИС-Мебельщик 2022.12.21, API 2341. Другие сборки требуют проверки.
3. Откройте model4.js штатным механизмом скриптов БАЗИС. На проверенном компьютере скрипты доступны через меню «Скрипты»; при размещении в папке Scripts они появляются в нём. Не запускайте CAD-скрипт через Node.js.
4. Введите три размера через пробел: например, `600 762 523`. Это ширина, высота корпуса без 100-мм опор и глубина с задником без 18-мм фасада. Диапазоны: 450…800, 712…862, 513…600 мм. Отмена или пустой ввод не меняют модель; неподдержанные значения отклоняются до очистки.
5. После сообщения об успехе проверьте изделие: 15 панелей, два фасада, три ящика, четыре опоры и оба профиля GOLA. На верхнем уровне два объекта, один из них служебная рамка; полный рекурсивный состав — 212.
6. Сохраните результат новым .b3d и откройте повторно. Для другого точного размера снова запустите скрипт: он пересоберёт изделие от исходного базиса. Произвольное ручное растяжение не является проверенным способом точного возврата всех служебных рамок (qa.md).

В журнал model4-last-run.json рядом со скриптом записываются ревизия, размеры, этап и дерево модели. При ошибке сохраните текст и журнал; после начала очистки частичный результат не считается готовым, автоматическое восстановление прежнего документа не обещается. Исправленный повторный запуск заменяет остатки.

Запуск и сохранение может выполнить человек или агент при разрешённом доступе. Исходная папка Модели не используется как место сохранения результатов. Комплект уже содержит model4-r02.b3d с исходными размерами 600×762×523. Производственные проверки перечислены в qa.md.
