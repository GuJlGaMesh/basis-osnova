# Решение r03

Удаление панелей из связанной нативной сборки исключено. Вместо AddPanel и восстановления только выгруженных свойств Model.Load загружает полный неизменный исходник; нативная идентичность панелей сохраняется вместе со связями. Зависимые внешние GOLA и отверстия включаются в общий блок с сохранением мирового положения, затем выполняется ElasticResize с проверкой принятого размера.

Операции загрузки, очистки, переопределения Owner, преобразований и ElasticResize проверены в БАЗИС 2022.12.21 / API 2341. Геометрические размерные цепи и диапазоны прежние. Нативное копирование всего связанного узла заменяет неполную реконструкцию панели по геометрии.

Причина Access violation по стеку не установлена. Нарушение связей при реконструкции — гипотеза; доказано отсутствие пользовательского симптома в выполненных проверках r03. Перед каждой нативной стадией пишется журнал, поскольку авария может обходить JavaScript catch.
