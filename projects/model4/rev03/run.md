# Запуск исправления r03

Откройте через меню «Скрипты» → «Model4-r03» → «model4». Ввод: три размера Ш В Г через пробел, например `600 762 520`. Диапазоны 450…800 / 712…862 / 513…600 мм. Высота без опор 100 мм; глубина с задником, без фасадов 18 мм.

При запуске скрипт очистит текущую модель и построит изделие заново; нужное содержимое сохраните заранее. Отмена и неверный ввод оставляют геометрию без изменений. Для новых размеров повторно запустите скрипт, чтобы не накапливались изменения служебных рамок.

Обязательная зависимость: соседняя папка lib с native-base.b3d. Копируйте src целиком. Журнал model4-last-run.json содержит этап, размеры и ошибку. Результат сохраните новым файлом. Приложен model4-r03.b3d 600×762×520.

r02 больше не использовать: её геометрические тесты не обнаружили сбой выделения. Производственный допуск этой исправленной модели не заявлен.
