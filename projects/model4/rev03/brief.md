# Паспорт r03

Исправление Access violation при выделении панелей r02. Параметры сохранены: W=450…800, H=712…862 без опор 100 мм, D=513…600 с задником без фасадов 18 мм. Исходный базис 600×762×523; приложенная модель построена для последних пользовательских размеров 600×762×520. БАЗИС 2022.12.21, API 2341.

Изменён способ переноса: полная исходная нативная сборка в src/lib/native-base.b3d сохраняет панели, соединения и фурнитуру вместе. Это параметрический скрипт на базе модели, а не независимая от библиотеки генерация панелей. При каждом запуске текущая модель заменяется после проверки входов. Производственные неизвестные и ограничения прямого растяжения r02 сохраняются.
