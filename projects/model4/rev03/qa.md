# Проверка исправления Access violation

> Архивная ревизия. Заключение об устранении сбоя выделения отозвано: API-выделение не покрывает подсветку связанных объектов мышью. Для запуска использовать [r05](../rev05/run.md). Числовые результаты ниже сохраняются как история проверок.

Статус скрипта: СКРИПТ ТРЕБУЕТ ИСПРАВЛЕНИЯ. Выполнен агентом в БАЗИС 2022.12.21 / API 2341. Статус модели по полным производственным gates: НЕ ПРОВЕРЕНО.

Пользователь сообщил об Access violation в Bazis.exe при выделении детали. Последний журнал r02 содержит успешное построение 600×762×520. Геометрические проверки r02 не включали обновление панели свойств при выделении и не доказывают пригодность модели к редактированию.

Гипотеза: удаление исходных панелей и создание новых в шаблоне, сохранившем нативные соединения, может нарушать внутренние ссылки. По сообщению с адресом памяти первопричина не установлена. В r03 проверяется перенос полной исходной сборки с сохранением идентичности панелей; разбор её на новые панели исключён. Дополнительно журнал записывает этап до нативной операции, чтобы при аварии оставалась последняя достигнутая точка.

Нужные проверки: выделение исходной и построенной боковины/фасада с обновлением свойств; повторное открытие; изменение размеров; сравнение геометрии. Производственный допуск не заявлен.


## Результаты

- PASS: 15 последовательных выделений панелей с обновлением панели свойств после построения 600×762×520; затем ещё 15 после сохранения и повторного открытия. Цикл использовал отдельный завершённый запуск скрипта для каждого выделения, а не флаги всех объектов в одном проходе. Счётчики: evidence/selection-index.txt и reopened-selection-count.txt; финальное окно свойств сохранено на снимке.
- PASS: 27 сочетаний размеров, 15 633 независимых геометрических утверждения; evidence/normalized/elastic-validation.json. Пути дерева нормализованы в схему предыдущего валидатора; сами измеренные значения не менялись.
- PASS: полные выгруженные свойства до/после повторного открытия совпали, r03-final.json / r03-reopened.json.
- PASS: синтаксис node --check и ASCII без BOM. Вызовы CAD проверены отдельно в БАЗИС.
- НЕ УСТАНОВЛЕНО: точное место Access violation в исходном коде БАЗИС. Старая авария подтверждена сообщением пользователя, а не новым контролируемым воспроизведением со стеком. Сохранение связанной сборки устранило симптом в выполненных пробах; внутренние ссылки остаются вероятной причиной.

Прежние файлы r02 не исправляются задним числом. Для работы использовать новую сборку r03. Способ моделирования изменён явно: панели больше не создаются заново, а сохраняются с нативными связями в полном шаблоне.
