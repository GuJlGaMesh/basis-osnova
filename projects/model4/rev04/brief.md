# Модель4 r04: добавление в сцену

Новый контракт пользователя: сохранять текущую модель, добавлять новый модуль и выравнивать по лицу. Каждый запуск добавляет отдельный экземпляр. Диапазоны W=450…800, H=712…862 без опор 100 мм, D=513…600 с задником без фасадов 18 мм. Состав, материалы и нативные связи перенесены из r03 без изменения.

Поддержан прямой ряд по глобальной X. Новый модуль ставится справа от существующих панелей вплотную, без промежутка. Лицо определяется по максимальной Z передних плоскостей панелей с нормалью вдоль Z; ручки и габаритные рамки не учитываются. В пустой сцене наружное лицо фасада Z=18. Повернутые и разнонаправленные ряды требуют отдельного задания базы.
