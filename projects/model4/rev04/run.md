# Запуск r04

Меню «Скрипты» → «Model4-r04» → «model4». Введите Ш В Г через пробел, например `600 762 520`. Будет добавлен новый модуль справа с выравниванием по лицу; прежние объекты сохраняются. Повторный запуск добавляет ещё один экземпляр.

Размеры в мм: ширина 450…800, высота без опор 712…862, глубина с задником без фасада 513…600. Папку src переносить целиком вместе с lib/native-base.b3d. Новый модуль можно переместить как отдельный блок. Не запускайте r03: та ревизия заменяет текущую сцену.

При отмене ввода ничего не добавляется. При ошибке журнал model4-last-run.json показывает стадию; удаляется только блок неудавшейся вставки. Сохраняйте результат средствами БАЗИС. Приложен пример из двух модулей разных размеров с общим лицом.
