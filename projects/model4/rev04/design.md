# Реализация r04

Входы проверяются до создания отдельного AddBlock. Полная нативная сборка загружается через holder.Load; после загрузки явно восстанавливается holder.Owner=Model. Старые объекты не удаляются, не перегруппировываются и не растягиваются. При ошибке удаляется только holder текущего запуска.

Изменение размеров выполняется внутри нового блока, как в r03. После этого holder.Position.X равен максимальной X существующих панелей (без дополнительного зазора); holder.Position.Z равен лицевой плоскости сцены минус (D−523+18). Разная глубина располагается сзади при общем лице. Повторный запуск добавляет ещё один блок.

API AddBlock, Block.Load, Owner, Position, преобразования, ElasticResize выполнены в БАЗИС 2022.12.21 / 2341. Успешная загрузка блока сама по себе не гарантирует его принадлежность сцене: это обнаружено при проверке и учтено явным Owner=Model. Нативные связанные панели не реконструируются отдельно.
