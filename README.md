# basis-osnova

Проектный контекст для ИИ, который собирает исходные данные, рассчитывает мебельную конструкцию и выдаёт готовый JavaScript-скрипт (`.js`) для БАЗИС-Мебельщика. Человек или агент при разрешённом доступе запускает скрипт в БАЗИС, проверяет и сохраняет рабочую модель.

## Tech Stack

- Целевая среда: **БАЗИС-Мебельщик 22** под Windows. Версия подтверждена пользователем; использовать её по умолчанию и не переспрашивать без сообщения о смене среды. В сеансе 2026-09-05 подтверждены сборка 2022.12.21 и `system.apiVersion = 2341`; совместимость отдельных методов проверяется отдельно.
- Автоматизация: JavaScript в среде БАЗИС с подтверждёнными операциями целевого API; скрипт подготавливает ИИ, открывает и запускает человек или агент при разрешённом доступе.
- Документация: Markdown, история изменений — Git.
- Проверка моделей: расчёты, измерения и осмотр в БАЗИС, сверка деталировки, технологический контроль.
- Репозиторий содержит инструкции и шаблоны для подготовки скриптов изделий. Проверки скрипта и фактической модели выполняются по отдельным критериям; наличие документации само по себе не означает автоматическую CAD-валидацию.

## Начало работы

1. Открой папку репозитория в ИИ-агенте, который читает `AGENTS.md`.
2. Передай задачу, например: «Спроектируй тумбу. Начни со сбора размеров по анкете проекта».
3. Агент уточнит критические данные и заполнит [паспорт изделия](docs/development/intake.md).
4. После согласования конструкции агент подготовит `.js` и [комплект для ручного запуска](docs/development/releases.md): паспорт, расчёт, инструкцию и отчёт подготовительных проверок.
5. Оператор (человек или агент) перенесёт комплект на компьютер с БАЗИС, откроет и запустит скрипт по [процессу БАЗИС](docs/development/bazis.md), сохранит модель и соберёт результаты проверок.
6. Готовность скрипта и готовность модели фиксируются отдельно по [quality gates](docs/development/quality-gates.md). Отсутствие БАЗИС на компьютере агента не блокирует подготовку и выдачу скрипта; проверку его выполнения и геометрии завершают после запуска.

Установка зависимостей для чтения документации не нужна. БАЗИС, его лицензия и библиотеки устанавливаются отдельно; этот репозиторий их не предоставляет.

## Пример запроса

> Нужна отдельно стоящая открытая тумба, наружные габариты Ш×В×Г 600×720×400 мм. Уточни материал, конструкцию, нагрузку и недостающие размеры. Сначала подготовь паспорт и размерные цепи, затем выдай готовый .js для ручного запуска в БАЗИС и отчёт подготовительных проверок.

Ожидаемый первый результат — заполненная часть паспорта и короткий список вопросов. Указанные габариты не определяют автоматически толщину плиты, устройство задней стенки и опор.
