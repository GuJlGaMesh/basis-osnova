# basis-osnova

Проектный контекст для ИИ, который проектирует мебель в БАЗИС-Мебельщике: собирает исходные данные, рассчитывает конструкцию, строит модель и проверяет результат.

## Tech Stack

- Целевая среда: БАЗИС-Мебельщик под Windows; версию и сборку фиксируют для каждого проекта.
- Автоматизация: JavaScript в среде БАЗИС, только с подтверждённой версией API.
- Документация: Markdown, история изменений — Git.
- Проверка моделей: расчёты, измерения и осмотр в БАЗИС, сверка деталировки, технологический контроль.
- Репозиторий содержит инструкции и шаблоны. Исполняемый генератор, автоматический CAD-валидатор и CI в эту инициализацию не входят.

## Начало работы

1. Открой папку репозитория в ИИ-агенте, который читает `AGENTS.md`.
2. Передай задачу, например: «Спроектируй тумбу. Начни со сбора размеров по анкете проекта».
3. Агент уточнит критические данные и заполнит [паспорт изделия](docs/development/intake.md).
4. После согласования конструкции агент подготовит скрипт или последовательность действий для установленной версии БАЗИС.
5. Итог сопровождается [протоколом проверок](docs/development/quality-gates.md). Без доступа к БАЗИС можно подготовить расчёт и код, но нельзя подтвердить корректность построенного файла.

Установка зависимостей для чтения документации не нужна. БАЗИС, его лицензия и библиотеки устанавливаются отдельно; этот репозиторий их не предоставляет.

## Пример запроса

> Нужна отдельно стоящая открытая тумба, наружные габариты Ш×В×Г 600×720×400 мм. Уточни материал, конструкцию, нагрузку и недостающие размеры. Сначала подготовь паспорт и размерные цепи, затем модель и отчёт по качеству.

Ожидаемый первый результат — заполненная часть паспорта и короткий список вопросов. Указанные габариты не определяют автоматически толщину плиты, устройство задней стенки и опор.
