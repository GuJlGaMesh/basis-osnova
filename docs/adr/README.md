# Решения проекта

| Документ | Решение |
|---|---|
| [ADR-0001](0001-evidence-based-modeling.md) | Параметры с источниками и проверка фактической модели |

Создавать ADR при изменении принципов совместимости API, определения размеров, владения объектами генератора или правил выпуска. Частное решение по одному шкафу хранится в расчёте изделия.

## Шаблон

```markdown
# ADR-NNNN: Название
Статус: предложено / принято / заменено
Дата: ГГГГ-ММ-ДД
## Контекст
Какая повторяющаяся проблема требует решения.
## Варианты
Варианты и последствия каждого.
## Решение
Выбранное правило и область действия.
## Последствия
Ограничения, проверки и условия пересмотра.
## Связи
Затронутые правила и заменённые ADR.
```
