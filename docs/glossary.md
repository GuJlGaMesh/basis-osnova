# Термины

| Термин | Значение в проекте |
|---|---|
| Наружный габарит | Максимальный размер согласованного состава изделия по заданной оси |
| Габарит корпуса | Размер корпуса; состав исключённых элементов перечисляют в паспорте |
| Чистый проём | Свободное расстояние между ограничивающими поверхностями |
| Заготовка | Деталь до согласованных операций обработки и облицовки |
| Готовая деталь | Деталь после предусмотренных операций, с учтённой облицовкой |
| Кромка | Облицовочный материал на торце панели |
| Присадка | Отверстия и связанные операции для соединений и установки фурнитуры |
| Наложение | Перекрытие фасадом опорной части корпуса |
| Функциональный зазор | Расстояние, необходимое для работы элементов |
| Монтажный зазор | Пространство для установки изделия в конкретные условия |
| Допуск | Допустимое отклонение контролируемого параметра |
| ГСК / ЛСК | Глобальная / локальная система координат |
| Размерная цепь | Связь размеров, определяющая итоговый габарит или проём |
| Деталировка | Перечень деталей с количеством, размерами и технологическими свойствами |
| Gate | Проверка, блокирующая следующий этап при несоответствии или отсутствии доказательств |
| Ревизия | Зафиксированная версия паспорта и связанных артефактов изделия |
