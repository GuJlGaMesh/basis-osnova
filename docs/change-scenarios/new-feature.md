# Новое изделие или возможность генератора

## Когда применять

Создание изделия, нового узла или новой функции автоматизации.

## Читать сначала

[Гейт скрипта](../development/gates/script.md), [паспорт](../development/intake.md), нужная [карточка мебели](../development/furniture/README.md).

## Шаги

1. Собрать параметры; критические значения подтвердить либо реализовать их обязательный ввод до построения.
2. Подготовить расчёт и конструкцию, затем `.js` по [процессу БАЗИС](../development/bazis.md).
3. Выполнить подготовительные [проверки](../development/testing.md) S0–S3.
4. Передать [комплект ручного запуска](../development/releases.md) со статусами скрипта и модели.
5. После запуска оператором получить доказательства по [гейту модели](../development/gates/model.md); отсутствие этого этапа не блокирует уже подготовленный комплект скрипта.

## Чеклист

- [ ] Подтверждены состав габаритов, материалы и конструкция.
- [ ] Выдан `.js` с инструкцией; результаты сверки фактической модели указаны отдельно либо отмечены NOT_RUN.
- [ ] Итоговый статус соответствует выполненным проверкам.

## Типовые ошибки

Предупреждаемые риски, а не история инцидентов: подстановка «стандартной» толщины, забытые опоры в общей высоте, оценка качества только по рендеру.
