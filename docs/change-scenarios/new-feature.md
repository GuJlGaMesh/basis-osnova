# Новое изделие или возможность генератора

## Когда применять

Создание изделия, нового узла или новой функции автоматизации.

## Читать сначала

[Архитектура](../architecture/overview.md), [паспорт](../development/intake.md), [конструирование](../development/modeling.md).

## Шаги

1. Собрать параметры и разрешить критические неизвестные.
2. Подготовить расчёт и конструкцию; закрыть G0/G1.
3. Проверить среду по [процессу БАЗИС](../development/bazis.md), построить на копии.
4. Выполнить [проверки](../development/testing.md), сохранить и открыть модель повторно.
5. Передать комплект с [протоколом](../development/quality-gates.md).

## Чеклист

- [ ] Подтверждены состав габаритов, материалы и конструкция.
- [ ] Фактическая модель сверена с расчётом.
- [ ] Итоговый статус соответствует выполненным проверкам.

## Типовые ошибки

Предупреждаемые риски, а не история инцидентов: подстановка «стандартной» толщины, забытые опоры в общей высоте, оценка качества только по рендеру.
