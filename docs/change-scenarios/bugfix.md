# Исправление ошибки модели

## Когда применять

Неверная геометрия, пропущенная деталь, ошибочная присадка или сбой скрипта.

## Читать сначала

[Архитектура](../architecture/overview.md), [quality gates](../development/quality-gates.md), [проверки](../development/testing.md).

## Шаги

1. Зафиксировать исходный файл и ревизию, ID дефекта, ожидаемый и фактический результат.
2. Воспроизвести на копии; определить источник: паспорт, формула, API, библиотека или операция.
3. Исправить первопричину и пересчитать зависимые элементы.
4. Повторить дефектный случай и затронутые проверки; добавить регрессионный случай при изменении генератора.
5. Обновить ревизию, измерить и переоткрыть итоговый файл; заменить прежний вердикт новым.

## Чеклист

- [ ] Исходный результат сохранён, причина установлена.
- [ ] Исправление не ограничено ручной правкой одного экземпляра при ошибке генератора.
- [ ] Доказательства относятся к исправленному файлу.

## Типовые ошибки

Предупреждаемые риски: подвинуть панель без исправления формулы; сохранить старую присадку после изменения толщины; оставить прежний PASS после правки модели.
