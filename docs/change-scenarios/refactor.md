# Рефакторинг генератора

## Когда применять

Изменение организации кода без намеренного изменения модели.

## Читать сначала

[Слои](../architecture/layers.md), [работа в БАЗИС](../development/bazis.md), [проверки](../development/testing.md).

## Шаги

1. Зафиксировать входные данные и измеряемый результат исходного генератора.
2. Отделить расчёт от CAD-операций и проверки результата без смены контракта параметров.
3. Сравнить размеры, количество, ориентации, материалы, кромки и присадку на одинаковых входных данных.
4. Проверить повторный запуск, отмену и сохранение в целевой среде.
5. При отличиях результата классифицировать их как отдельное изменение конструкции, а не скрывать под рефакторингом.

## Чеклист

- [ ] Сохранены параметры и владение объектами.
- [ ] Сравнение выполнено по свойствам модели.
- [ ] Необъяснённых изменений геометрии и операций нет.

## Типовые ошибки

Предупреждаемые риски: сравнивать только текст кода или байты файла; потерять локальную систему координат при выделении общей функции.
