# Среда и источники

| Зависимость | Что фиксировать |
|---|---|
| БАЗИС-Мебельщик | Версия, сборка, доступные модули и способ запуска |
| API скриптов | Подтверждённая версия, справка и минимальный проверенный пример |
| База материалов | Артикул, толщина, декор, текстура, кромка и правила учёта размеров |
| Библиотеки фурнитуры | Производитель, артикул, ревизия и схема установки |
| Производство | Доступные операции, допуски, оборудование и постпроцессор при необходимости |

## Официальные точки входа

Ссылки проверены 2026-09-05. Соответствие установленной версии устанавливают заново для каждого профиля среды.

- [Руководства БАЗИС](https://bazissoft.ru/file/guide) — выбор руководства нужного модуля.
- [Раздел скриптов](https://bazissoft.ru/file/guide/skript) — руководство, примеры и описание функционала.
- [Работа со скриптами](https://cdn.bazissoft.ru/documentation/ru/Script.pdf) — базовый порядок работы с файлами JavaScript в редакторе БАЗИС.
- [Официальные примеры API](https://cdn.bazissoft.ru/documentation/ru/BAZIS-Script_examples.html) — документ объявляет версию API 5; это не версия установленной программы пользователя.
- [Функционал API](https://cdn.bazissoft.ru/documentation/ru/BAZIS-Script_functions.html) — проверка имён, параметров и поведения операций.

При использовании источника записывают URL или путь локальной справки, раздел, дату обращения и применимую версию в `design.md` изделия. Схемы фурнитуры берут у производителя конкретного артикула; универсального каталога крепежа этот проект не устанавливает.

Если источники расходятся, регистрируют противоречие. Для совместимости сверяют локальную справку и пример на целевой сборке; для монтажа — документацию производителя и согласованные требования производства. Не устраняют противоречие догадкой.
