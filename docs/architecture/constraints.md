# Ограничения

- Версия приложения, версия API и комплект библиотек — разные параметры. Наличие свежего руководства в интернете не подтверждает доступность его методов в установленном БАЗИС.
- Выполнение JavaScript вне БАЗИС проверяет только независимые расчёты. Оно не доказывает создание панелей, кромок, отверстий или корректность сохранения.
- Изображение и скриншот не задают скрытые размеры, толщины и присадку. Перспективное изображение без масштаба не является обмером.
- Производственные допуски, нагрузки, прогиб, анкеровка и соединения зависят от материалов, фурнитуры и условий монтажа. Общих безопасных значений по умолчанию нет.
- БАЗИС установлен на другом компьютере: отсутствие локального приложения, лицензии или инструмента управления окном не блокирует подготовку и выдачу `.js` по [правилам передачи](../development/releases.md). Открытие и запуск выполняет человек; статус выполнения и фактической модели остаётся неподтверждённым до получения доказательств из БАЗИС.
- Недостающие критические размеры блокируют зависимое построение: их уточняют заранее либо реализуют обязательный ввод с проверкой при ручном запуске. Неподтверждённые необходимые операции API требуют источника или проверенного примера; ограничение среды не разрешает выдумывать методы либо выдавать заглушки за готовый скрипт.
- Экспорт для ЧПУ требует отдельной проверки оборудования, инструмента, базирования и постпроцессора. Модель сама по себе не даёт допуск к обработке.
