# Границы доказательств

| Источник | Что ограничивает вывод |
|---|---|
| Руководство или декларации API | Не подтверждают наличие и работу метода в другой сборке; проверка совместимости — по [сценарию API](../change-scenarios/api-change.md) |
| Проверка JavaScript вне БАЗИС | Подтверждает проверенную часть расчёта и поведения кода, но не CAD-операции; граница — [гейт скрипта](../development/gates/script.md) |
| Фото, превью, подписи или частичный разбор файла | Не задают скрытые размеры и актуальный состав; применять [правила извлечения знаний](../development/reference-models.md) |
| Геометрически правдоподобная модель | Не доказывает нагрузки, монтаж и производимость; нужны [проверка модели](../development/gates/model.md) и [допуск](../development/gates/production.md) |
| Отсутствие доступа к БАЗИС | Позволяет завершить подготовку скрипта, но оставляет непроведённые проверки фактической модели NOT_RUN |

Неизвестные исходные данные и запрет выдумывать методы регулируют [обязательные правила](../development/rules.md). Численные ограничения материалов, нагрузок и оборудования получают из источников конкретного изделия; общие значения по умолчанию этот справочник не устанавливает.
