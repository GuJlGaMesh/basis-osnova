# Архитектура процесса

Цель — воспроизводимое проектирование мебели с прослеживаемыми исходными данными и проверками. Область по умолчанию — корпусная мебель из плитных материалов. Для металлокаркаса, мягкой мебели, сложной криволинейной конструкции или нестандартных нагрузок сначала разрабатывают отдельные правила и критерии.

Поток: запрос → паспорт изделия → размерные цепи и конструкция → скрипт или действия в БАЗИС → сохранённая модель → независимые измерения и деталировка → решение о готовности.

Паспорт хранит намерение пользователя. Модель хранит фактическую геометрию. Протокол сравнивает одно с другим; расчёт генератора не может одновременно быть единственным доказательством его правильности.

ИИ собирает параметры, предлагает конструкцию и выполняет доступные проверки. Пользователь подтверждает исходные данные и проектные решения. Технолог проверяет производимость и принимает решение о запуске в изготовление. Эти роли можно совмещать, но факт проверки и проверяющего записывают явно.
