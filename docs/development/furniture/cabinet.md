# Корпусная мебель: шкафы, тумбы и стеллажи

## Входные данные

По [паспорту](../intake.md) определить состав наружного габарита, толщины деталей, расположение дна/крышки, задник, опоры, фасады, назначение и нагрузку полок. Для навесного изделия нужны основание и схема крепления, для встроенного — обмер и монтажные зазоры. Прямоугольный корпус не означает автоматически пригодности для конкретной нагрузки или помещения.

Панели, контуры, кромки и соединения — по [общим правилам](../modeling.md). Если есть [ящики](drawers.md) или [кухонные узлы](kitchen.md), добавить только эти карточки.

## Учебный расчёт открытого корпуса

Только для двух боковин полной высоты, дна и крышки между боковинами, без задника, фасадов, опор, пазов и влияния кромки. Параметры W/H/D — наружные габариты корпуса; t — одинаковая толщина плит.

- Боковины: 2 детали H×D, толщина t.
- Дно и крышка: 2 детали (W−2t)×D, толщина t.
- Чистый проём: (W−2t)×(H−2t).
- Съёмная полка при согласованных боковых зазорах cL/cR: ширина W−2t−cL−cR. Её глубину задают отдельно с учётом переднего/заднего отступов и фурнитуры.
- Предусловия: W>2t, H>2t, D>0, t>0, cL≥0, cR≥0 и положительные размеры всех деталей.

Пример для проверки арифметики: W=600, H=720, D=400, t=18 мм → боковины 720×400, дно/крышка 564×400, проём 564×684 мм. Это учебные значения, а не рекомендуемая конструкция и не допуск в производство.

Для двух одинаковых фасадов над одним прямоугольным проёмом ширины O формула `(O−gL−gR−gMid)/2` применима лишь при согласованных границах покрытия и зазорах. Накладные фасады требуют другой базы O с учётом наложения. Зазоры и количество петель не назначают по этому примеру.

## Полки с заданными и автоматическими промежутками

Для вертикального проёма высоты H и n горизонтальных полок промежутков n+1. Пусть T — сумма фактических толщин полок, S — сумма заданных чистых промежутков, k — количество остальных промежутков. При равномерном распределении остатка каждый автоматический промежуток равен `(H−T−S)/k`. Для одинаковых полок толщины t сумма T равна `n×t`. Высота H измеряется между внутренними границами проёма; толщины ограничивающих его дна и крышки повторно не вычитаются.

Признак автоматического промежутка хранить отдельно от его числового значения. Проверять целое неотрицательное количество полок, толщины и допустимость промежутков. При k=0 не выполнять деление: сумма `T+S` должна совпадать с H в пределах заданного численного допуска. При k>0 остаток должен удовлетворять минимальным промежуткам выбранной конструкции; отрицательный остаток отклонять до построения. Формула распределения не подтверждает допустимость пролёта, нагрузки или монтажных отступов крепежа.

## Проверки по гейтам

| Gate | Специальная проверка |
|---|---|
| G0/G1 | Габарит корпуса отделён от фасадов и опор; цепи проёмов и полок замыкаются при фактических толщинах |
| G3/G4 | Размеры и стороны деталей, текстура и кромки соответствуют расчёту, повёрнутые и зеркальные детали проверены отдельно |
| G5/G6 | Соединения доступны для сборки; полки, задник и крепление изделия выдерживают согласованные нагрузки по расчёту или документации |

Для учебного случая выше проверить 4 панели, наружный габарит 600×720×400 и размеры 720×400 и 564×400 по две детали. При замене t=18 на t=16 и прежних наружных размерах ширина дна/крышки становится 568, проём — 568×688. Проверить W≤2t, H≤2t, нулевую толщину, полностью заданные промежутки, недостаток высоты и смешанное автоматическое распределение. Эти числа проверяют арифметику учебной схемы, а не производственную конструкцию.
