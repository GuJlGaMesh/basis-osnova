# Передача результата

Каждое изделие получает ID и ревизию. Изменение паспорта, геометрии, материала, присадки или значимых настроек создаёт новую ревизию. Не перезаписывать единственный проверенный экземпляр.

## Комплект выдачи

- Паспорт с подтверждениями и расчёт конструктивных решений.
- Нативная модель БАЗИС, сохранённая средствами целевой версии; расширение не угадывают и не меняют переименованием другого формата.
- Исходный скрипт и инструкция запуска, если использовался генератор.
- Деталировка и согласованные чертежи, спецификация материалов/кромок/фурнитуры.
- Протокол G0–G8 и доказательства, связанные с той же ревизией модели.

Состав экспортов может быть сокращён для эскиза с явной записью применимости в протоколе. Производственный комплект определяет принимающий технолог; файлы ЧПУ требуют отдельного допуска.

## Порядок

Сохранить файл → открыть заново → завершить проверки → сформировать экспорты из проверенной ревизии → сверить позиции, количество и размеры → записать контрольную сумму → передать комплект с итоговым статусом и незакрытыми пунктами.

Контрольную сумму можно получить в PowerShell командой `Get-FileHash -Algorithm SHA256 -LiteralPath 'путь-к-реальному-файлу'`, подставив существующий путь. Хеш связывает доказательства с файлом, но не доказывает качество геометрии.

Если приложение недоступно, передают подготовительные артефакты с формулировкой «Запуск и модель в БАЗИС не проверены», перечнем оставшихся gates и точной инструкцией для оператора. Подмена нативной модели картинкой или кодом недопустима.
