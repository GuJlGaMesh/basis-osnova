# Метод ревью

Сначала определить предмет: исходник и комплект, фактическая модель или производственный пакет. Применить соответствующий [гейт](quality-gates.md) и [карточку мебели](furniture/README.md); критерии готовности здесь не переопределяются.

Сопоставлять запрос, паспорт, независимый расчёт и фактические артефакты. Проверять изменения размерных цепей, а не только изменённые строки: одна толщина может затронуть проёмы, фасады, присадку и монтаж. Для изменений API или способа вставки сравнивать содержательные свойства моделей; побайтовое равенство CAD-файлов не является критерием геометрии.

В ревью кода проверить границы мутаций и обработку отказов по [контракту скрипта](bazis.md). Это анализ реализации; сохранность сцены при выполнении подтверждается отдельно в G2. Повторный просмотр собственного расчёта не считается независимым измерением модели.

Замечание содержит ID детали/параметра, ожидаемое и фактическое поведение, доказательство, последствия и требуемую повторную проверку. Дефект блокирует затронутый gate; косметическое замечание к описанию не заменяет исправление дефекта. Результаты записываются по [общим правилам](quality-gates.md), без утверждений о непроведённых проверках.
