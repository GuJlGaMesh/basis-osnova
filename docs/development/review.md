# Ревью модели и изменений

Ревью начинается с паспорта и фактического результата, а не с комментариев генератора. Критерии — [quality gates](quality-gates.md), ограничения — [правила](rules.md).

Проверяющий сопоставляет исходный запрос, подтверждённые параметры, формулы, детали, сохранённый файл и его экспорты. Проверяет, что предложения не стали исходными данными без ответа, методы API подтверждены, повторный запуск и отмена определены, а учебный пример не выдан за производственный стандарт.

При изменении размеров или толщины отдельно проверить зависимые проёмы, фасады, полки, ящики, кромки, присадку и монтаж. При изменении только кода сравнивать геометрию и технологические свойства, а не побайтовое равенство CAD-файлов.

Замечание должно содержать ID детали/параметра, ожидаемое и фактическое поведение, доказательство, последствия и требуемую повторную проверку. Дефект геометрии, монтажа, материала или производственных данных блокирует затронутый gate; косметическое замечание к описанию не должно скрывать этот блокер.

Не переносить в отчёт утверждения «прошло», если проверку не выполнили. Повторный просмотр собственного расчёта полезен, но не считается независимым измерением модели.
