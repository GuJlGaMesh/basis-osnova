# Работа над изделием

Начинай с [паспорта и вопросов](development/intake.md). Затем пройди [конструирование](development/modeling.md), [построение в БАЗИС](development/bazis.md), [контроль качества](development/quality-gates.md) и [выпуск](development/releases.md).

Два обязательных рабочих документа для каждого изделия — паспорт и протокол проверок. Их копируют из шаблонов в отдельную папку изделия по [правилам размещения](architecture/layers.md). Шаблоны не заполняют данными заказа.

Основные [правила](development/rules.md) действуют для ручной работы и скриптов. [Глоссарий](glossary.md) помогает одинаково понимать размеры и операции. [Навигация ИИ](AGENTS.md) выбирает минимальный контекст для задачи.

Технические сведения сверяют по [официальным источникам](architecture/dependencies.md). Проектные формулы и quality gates являются правилами этого репозитория, а не заявлением о встроенных проверках БАЗИС.

[Работа с примерами](development/reference-models.md) объясняет, как извлекать общие мебельные знания из моделей и проверять их применимость. Для кухонного модуля с ящиками и GOLA использовать специальные вопросы анкеты и дополнительные критерии quality gates.
