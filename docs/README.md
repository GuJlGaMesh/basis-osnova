## Как обновлять справочник

Сначала найти владельца правила в таблице и изменить существующий раздел. В остальных местах оставлять ссылку, не вторую формулировку. Карточка мебели не переопределяет гейты, сценарий не копирует комплект файлов, протокол не становится общей нормой. Данные конкретного заказа и диагностические журналы остаются в `projects/<ID>/<rev>/`.

При добавлении карточки обновить [маршрутизатор](AGENTS.md) и [индекс мебели](development/furniture/README.md). Новая карточка нужна для отдельного устойчивого типа конструкции, а не для каждого размера или файла модели. Новые команды запуска и возможности API описывать только после подтверждения; не превращать предлагаемый приём в якобы существующий инструмент.

При переносе документа обновить активные ссылки и якоря; если старый адрес используется в выпущенных комплектах, сохранить короткий указатель без копии содержания. Проверить ссылки, уникальность критериев гейтов и сохранность технических ограничений. Архивные комплекты изделий не переписывать ради новой структуры справочника.
